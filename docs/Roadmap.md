# Roadmap

## Phase 1 - Foundation

- Establish the application shell
- Define the design system
- Build the first dashboard experience
- Keep the architecture privacy-first and planning-oriented

## Phase 2 - Planning Core

- Expand income, debts, and payments workflows
- Add financial goals as a first-class product area
- Improve visibility into upcoming obligations
- Strengthen the user-owned data model

## Phase 3 - Forecasting

- Introduce simple forecasting views
- Help users compare scenarios and outcomes
- Surface decision-oriented insights without automation or bank dependency

## Phase 4 - Financial Health

- Add stronger health indicators
- Improve goal progress visibility
- Support better prioritization across goals, debts, and liquidity

## Phase 5 - Trust and Scale

- Harden security and privacy controls
- Expand offline-friendly capabilities
- Improve documentation and product consistency

## Product Direction

SNXW Finance will continue evolving as a personal financial planning platform focused on:

- Privacy First
- Security First
- User data ownership
- Planning and forecasting
- Financial health
- Better financial decisions
