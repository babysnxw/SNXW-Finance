# 💸 SNXW Finance

> Not just a finance tracker. A financial decision copiloto.

---

## 🚀 What is SNXW Finance?

SNXW Finance is an intelligent personal finance system designed to help users **make better financial decisions**, not just track expenses.

Instead of asking:

> "How much did I spend?"

It answers:

> "Can I afford this without breaking my future payments?"

---

## 🧠 Core Idea

Traditional finance apps show history.

SNXW Finance shows **impact**.

It helps answer questions like:

- What happens if I pay this debt early?
- How much can I safely spend this week?
- Which credit card should I pay first?
- What is my real financial risk right now?

---

## 🎯 Vision

To become an open-source financial copilot that helps people:

- Understand their financial reality
- Reduce debt intelligently
- Improve cash flow planning
- Make confident financial decisions

---

## ⚙️ Tech Stack (Planned)

- Flutter (Cross-platform UI)
- Dart (Core language)
- Riverpod (State management)
- Drift + SQLite (Local database)
- Clean Architecture (Scalability & structure)

---

## 🧩 Architecture Philosophy

SNXW Finance is built under these principles:

- 🧱 Clean Architecture first
- 🔒 Offline-first by design
- 📦 Modular and scalable structure
- ♻️ Reusable components over duplication
- 📊 Data-driven financial insights

## 🧪 MVP (First Version)

The first version of SNXW Finance will focus on:

- Manual income & expense tracking
- Debt tracking (credit cards, loans)
- Basic financial overview dashboard
- Simple cash flow visibility

---

## 🚫 What this is NOT (yet)

- Not a banking app
- Not a crypto trading app
- Not a stock investment platform
- Not a complex ERP system

We are starting small, but thinking big.
